# License collection decisions

The portable ZIP retains original installed LICENSE/NOTICE/COPYRIGHT files for the reachable frontend and Windows Cargo dependency graphs. This is a practical attribution inventory, not legal certification.

## Tauri packages with incomplete npm/crate license-file packaging

- `@tauri-apps/plugin-dialog@2.7.1` declares `MIT OR Apache-2.0` in its installed `package.json`. Its distributed `dist-js/index.js` carries `Copyright 2019-2023 Tauri Programme within The Commons Conservancy` and SPDX identifiers for both licenses; `LICENSE.spdx` carries the earlier 2019-2022 notice. Both original notices are retained. The MIT permission/disclaimer text is the actual text distributed by the same Tauri upstream in `tauri@2.11.5/LICENSE_MIT`. The package is distributed under the offered MIT alternative; the original copyright holder notice is added, not replaced by the core package's contributor notice.
- `tauri-plugin@2.6.3` declares `Apache-2.0 OR MIT` in its cached manifest and identifies `https://github.com/tauri-apps/tauri` as the repository. Its `src/lib.rs` carries `Copyright 2019-2024 Tauri Programme within The Commons Conservancy` with both SPDX identifiers. The permission/disclaimer is the same upstream's actual MIT text; the plugin's own original copyright notice is retained.

These decisions apply only to those exact declared versions/identifiers. They do not license unlicensed packages, infer a copyright owner from a name, or borrow unrelated package terms. Original package/source notice material is included alongside the supplement. For a public release, independently review the full inventory and Microsoft runtime redistribution terms.

## Frontend packages with incomplete metadata

- `khroma@2.1.0` omits the `license` field from its installed `package.json`, but that exact package includes a complete lowercase `license` file stating MIT, retaining `Copyright (c) 2019-present Fabio Spampinato, Andrew Maney`, the permission grant and disclaimer. The collector accepts only version `2.1.0` with repository `github:fabiospampinato/khroma` and those bundled text markers; another version, repository or text fails closed.

## WebView2 Rust bindings and Microsoft SDK

- `webview2-com@0.38.2` / `webview2-com-sys@0.38.2` identify `wravery/webview2-rs` as the repository. The omitted root MIT license was retrieved through the GitHub contents API at recorded commit `b74dc5e2b394044bea5191052868ce7a106c202c`; the macros crate at `dffa41a8a46d3f5565eefbff2de57d38d399f158` returns the identical license blob `de9a7e660e173136b351982a34f715af424ff812`. The original 2021 Bill Avery notice is retained in `WebView2-Rust-MIT.txt`.
- The verified `webview2-com-sys@0.38.2` crate changelog states Microsoft WebView2 SDK `1.0.3650.58`. Its x64 loader and static loader libraries are bundled by that crate. `WebView2-SDK-License.txt` is the complete BSD-style copyright/conditions/disclaimer served by the official NuGet package license endpoint: https://www.nuget.org/packages/Microsoft.Web.WebView2/1.0.3650.58/License . System WebView2 Runtime is not bundled.
- `MSVC-BuildTools-Terms.txt` is paragraph text extracted from Microsoft's linked March 2024 Chinese Build Tools terms document. `Windows-SDK-License.txt` is text extracted from the installed Windows SDK `10.0.26100.0` license. They are retained for reference rather than represented as open-source licenses or a redistribution compliance certificate. No compiler, SDK headers or standalone static libraries are shipped in the Leaf ZIP.

## Other crates with omitted top-level terms

- `alloc-stdlib@0.2.4` records commit `ae42d22078b98549e987d2f03d12df7b984fde47` and subdirectory `alloc-stdlib` in `.cargo_vcs_info.json`. The root `LICENSE` from `dropbox/rust-alloc-no-stdlib` at that commit is retained unchanged in `Dropbox-Alloc-BSD-3-Clause.txt` (Git blob `cd496ba72eb37e83a44958358d1f89a8a28cbc15`), including the 2016 Dropbox copyright, all three conditions and disclaimer.
- `unic-char-property`, `unic-char-range`, `unic-common` and `unic-ucd-version` at `0.9.0` record commit `5878605364af97a3358368a6eaef02104af2e016`; `unic-ucd-ident@0.9.0` records `8a6ce83063d90b91ae2ce59eddb803edd393fca9`. The root MIT text, copyright and author list are identical at both recorded `open-i18n/rust-unic` commits (Git blobs `31aa79387f27e730e33d871925e152e35e428031`, `0322ceec0b8f15aa2d74a6173c07cc8c6f3764b3`, `ab3575c1f490363e4957adbc77a3783c48f4492b`). Those files are retained as `UNIC-MIT.txt`, `UNIC-COPYRIGHT.md` and `UNIC-AUTHORS.txt`; each crate's own 2017 or 2017-2019 source notice is also retained. These exact versions are distributed under their offered MIT alternative.
- `selectors@0.36.1` declares MPL-2.0 and records `servo/stylo` commit `635e1a19d02960588a00e189bd4bd5bdb150ec3d`. Its source notice explicitly points to Mozilla's MPL 2.0. `Mozilla-MPL-2.0.txt` is the complete official plain text fetched from https://www.mozilla.org/media/MPL/2.0/index.txt (SHA-256 `3f3d9e0024b1921b067d6f7f88deb4a60cbe7a78e76c64e3f1d7fc3b779b9d04`). The portable package includes the unmodified locked crate's Source Code Form at `third-party-sources/selectors-0.36.1` and gives source location/rights information in `THIRD-PARTY-SOURCES.txt`; it does not claim that retaining a license identifier alone satisfies source availability.

The portable package also includes unmodified Source Code Form for the other exact MPL-2.0 crates (`cssparser`, `cssparser-macros`, `dtoa-short`, `option-ext`) under `third-party-sources/`. Source files and their original notices are copied from the locked local Cargo cache without modification; no source-package build scripts are executed while collecting them. This deliberately includes build-time as well as runtime graph entries.

The supplemental rules verify exact package name, version, declared license, repository, recorded commit and source notices where applicable. A changed or missing provenance record fails closed rather than silently reusing terms for a new version.
