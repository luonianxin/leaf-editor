# Leaf 0.5.0 Markdown 格式工具栏（待实现）

## 用户确认

在 0.4.0 发布构建进行期间，用户要求参考此前 MarkFlow 截图的上方工具栏，在下一个版本实现。本文件记录需求，不将其混入当前 0.4.0 构建。

## 范围

- 在现有文件操作栏基础上增加 Markdown 格式操作区，优先呈现图中清楚可辨的操作：加粗、斜体、删除线、行内代码、H1/H2、引用、链接、无序/有序列表、分隔线、代码块、图片语法、插入表格。
- 文件打开、新建、保存、侧栏及文件/大纲沿用已有能力；截图中含义不明确的图标不擅自映射为新功能。
- 左下角源码/预览模式入口继续保留，不因截图在顶部展示切换而重复移动入口。
- 所有操作编辑当前 CodeMirror Markdown 源文，作用于选区或当前行；无选区时插入可继续输入的模板，执行后将光标定位到编辑位置。
- 按钮有中文名称/提示、合理禁用态、键盘可达和明暗主题样式；窄窗口折叠次要动作，避免拥挤或页面横向溢出。
- 非 Markdown 文件不显示或禁用 Markdown 格式按钮；不能误改普通文本。
- 每次格式操作产生一次可撤销事务；保留选区、跨模式/跨文件历史隔离与未保存状态；输入法组合期间不能打断输入。
- 表格按钮插入 GFM 模板（可选择初始行列数）；沿用 0.4 表格渲染/点击源码交互，不承诺直接可视增删行列。
- 图片按钮只插入 Markdown alt/路径语法，不自动上传、下载、读取本地图片或放宽权限。
- 链接按钮只编辑 Markdown 语法，不因插入动作导航或执行协议。

## 不随本需求自动纳入

截图不能确定的导出、设置、分屏、富文本单元格编辑、图表/公式渲染等能力不直接视为已确认。既有保存机制不变，不新增编辑器依赖。Vditor 仍不引入。

## 验收

逐项覆盖选区/空选区/多行/Unicode/撤销重做、切换模式与标签、禁用态、窄屏和浅深主题；真实浏览器操作和截图后，使用新构建 Windows EXE 验收。明确记录真实中文输入法测试是否执行。
