# Leaf 0.4.0 Markdown 表格渲染与源码编辑规格

状态：已作为 0.4.0 正式实现并打包。34 项单元测试、10/10 浏览器回归、9/9 Rust 文件模块及全新解压 EXE 的完整原生交互通过；manifest 86 项哈希全部核对。正式包信息见 ../../VERIFICATION.md。WebView 子进程历史上曾间歇超过 15 秒才退出，本轮两次清理均在 1 秒内，但不宣称根因已修复。

## 决策变更

本规格取代此前的 Vditor/Milkdown 富文本编辑原型路线。用户明确拒绝引入 Vditor，确认保留 CodeMirror + 已有 Marked，不新增编辑器依赖。首要任务是补齐 GFM 表格渲染，不把源码样式装饰称为所见即所得。

历史选型研究仅作为背景，不再授权安装或接入第三方富文本编辑器。

## 本次范围

- 保留左下角“源码模式 / 预览模式”，以及现有正文即时编辑。
- 预览模式中，非正在编辑的 GFM 表格显示为实际 HTML 表格：表头、边框、列对齐、单元格行内格式、横向滚动。
- 点击表格或键盘激活“编辑表格源码”进入该表格的 CodeMirror 原始文本范围，不创建另一份草稿，不修改其他段落。
- 光标/选择范围触及表格时显示其源码；离开表格或使用明确的完成预览操作后恢复渲染。组成输入过程中不得强制切换。
- 源码模式始终显示完整 Markdown。表格编辑沿用同一 EditorView、文档、选区与撤销历史。
- 不支持的语法原样保留；无有效 GFM 分隔行的内容保持普通文本；代码围栏中的管道不得误渲染。

## 非本次范围

直接编辑渲染后的单元格、Tab 单元格导航、可视增删行列、富文本工具栏、Mermaid/公式渲染、新编辑器内核均延期。点击后编辑整表源码是本次明确约定的交互，不宣称直接单元格所见即所得。

## 内容安全与技术边界

1. Markdown 源文是唯一数据源。模式切换/渲染不写回、不置 dirty、不产生编辑历史；绝不执行 HTML→Markdown 全文转换。
2. 使用 CodeMirror 状态驱动的块级装饰替代表格；块替换不可由 viewport ViewPlugin 提供，避免 CodeMirror 禁止跨行替换的限制。
3. 表格范围须由语法解析定位，处理多个表格、转义管道、围栏、文档变化、撤销以及切文件，禁止过期位置回写。
4. 使用现有安全 Marked renderer；HTML 转义、图片占位、链接不导航，无远程资源请求；渲染 DOM 不拥有文件读写权限。
5. 已有 524,288 UTF-16 代码单元阈值以上回落源码式编辑，不同步渲染巨表；明确限制并测试边界。表格解析/渲染依赖按需启用，不影响普通文件。
6. 保留目录选择弹窗、文件树、编码/换行、冲突/原子保存及未保存保护，不覆盖已有 0.3 包和未提交改动。

## 验收标准

- GFM 表头、左右/居中对齐、粗体/代码等行内格式正确，长表格可横向滚动；浅深主题可读。
- 多表格点击编辑定位正确；编辑后恢复渲染、源码切换、撤销/重做、文件切换和保存重开均正确。
- 修改表格仅改变用户实际输入的范围，前后正文、注释、Frontmatter、空白和尾部换行保持原样；无操作切换不变更文档。
- 光标/多选触及表格不隐藏所选源码；中文输入组合不被装饰重建打断。自动化中文文本输入不冒充真实输入法验收。
- 原始 HTML、远程图片、可执行链接、围栏假表格测试通过；无外部请求、无新增权限。
- 单元测试、类型检查、构建、真实浏览器操作及截图通过后报告；Windows 新 EXE 验收与打包另记具体哈希，不沿用旧包结果。

## 实施顺序

1. 语法范围和表格块装饰实现，补充范围/安全测试。
2. 接入现有即时预览，完成进入源码和恢复表格的交互。
3. 浏览器回归：多表格、保真、撤销、切换、样式和安全；记录限制与失败。
4. 更新用户说明，再执行新 EXE 的专项回归；未完成前不宣称交付。
